# IT Support Ticket Management System

## Project Description

The IT Support Ticket Management System is a Python-based application
developed using Tkinter and MySQL.

It allows users to create and manage IT support tickets and allows
staff members to view, search, update and monitor tickets.

## Technologies Used

- Python
- Tkinter
- MySQL
- mysql-connector-python

## Features

- User Registration
- User Login
- Staff Login
- Create Support Ticket
- View My Tickets
- Search and Filter Tickets
- Update Tickets
- Delete Tickets
- Staff Dashboard
- Update Ticket Status
- Add Resolution
- Ticket Statistics
- File Handling
- Exception Handling

## Database

MySQL is used to store:

- Users
- Staff
- Tickets

## How to Run

1. Install Python.
2. Install MySQL.
3. Create the `it_support` database.
4. Create the required tables.
5. Install the MySQL connector:

pip install mysql-connector-python

6. Configure the MySQL username and password in `database.py`.
7. Run `main.py`.
